## 🌌 Overview

**Nexus** is an ultra-high performance web platform showcasing an autonomous cognitive infrastructure layer. Designed for sub-millisecond edge neural routing, zero-knowledge confidential computing enclaves, and coordinated multi-agent swarm intelligence at planetary scale.

---

## ✨ Key Features

- ⚡ **Interactive Live Studio**: In-browser neural execution simulator with real-time token streaming, multi-language synthesis (Rust, TypeScript, Python), and telemetry traces.
- 🎨 **Adaptive Multi-Theme Engine**:
  - **OLED Dark Mode** (Default deep cosmic aesthetic)
  - **Clean Paper Light Mode** (High-contrast minimalist typography)
  - **Cyberpunk Terminal Mode** (CRT phosphor green aesthetic)
- 🌐 **Interactive Particle Constellation**: Pure HTML5 Canvas physics engine reacting dynamically to mouse proximity, velocity, and theme colors.
- 🔊 **Zero-Dependency Synthesizer**: Native Web Audio API sound generator providing subtle audio feedback for interactive elements without loading bulky MP3 assets.
- ⌨️ **Command Palette (`Cmd+K` / `Ctrl+K`)**: Keyboard-driven navigation modal with fuzzy command matching and direct shortcuts.
- 📊 **Dynamic ROI & Latency Calculator**: Real-time compute cost estimation and latency savings calculator.
- 🛡️ **Zero-Knowledge Architecture Visualizer**: Interactive 5-stage pipeline inspector detailing Anycast Ingress, Neural Routing, Swarm Core, ZK Enclave, and Streaming Egress.
- 📱 **Fully Responsive & Accessible**: Semantic HTML5 markup, ARIA roles, responsive typography, and mobile drawer navigation.

## 🚀 Local Development

To run and preview the website locally:

```bash
# Clone the repository
git clone https://github.com/nxtzenmaker-max/eager-nexus-621.git
cd eager-nexus-621

# Serve with any static web server (e.g. Python, Node.js, Caddy, Nginx)
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.
